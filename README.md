# Neon Dodge

A lightweight, responsive HTML5 arcade survival game. No frameworks, build tools, or dependencies required.

## Play locally
Open `index.html` in a modern browser.

## Deploy with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish your site. The URL will appear in the Pages settings.

## Controls
- Desktop: `←` / `→` or `A` / `D`
- Pause/resume: `Space`
- Mobile: use the on-screen arrow buttons
- Best score is saved in the browser's local storage.
